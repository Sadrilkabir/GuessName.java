# Java Name Guessing Program

A simple Java console program where the user tries to guess a predefined name.

## How It Works

The program asks the user to guess a name.

- If the user enters the correct name, the program displays a success message.
- If the guess is incorrect, the program displays a wrong-answer message.
- The user can type `stop` to exit the program.

## Technologies Used

- Java
- Java Scanner
- If statements
- While loops

## How to Run

1. Make sure Java is installed on your computer.
2. Compile the program:

```bash
javac GuessName.java
